# SmartStudy User Guide

## 🎯 Welcome to SmartStudy

SmartStudy is your AI-powered learning companion that transforms any document into interactive quizzes and guided learning experiences. Whether you're a student, educator, or professional, SmartStudy helps you learn more effectively through intelligent AI assistance.

## 🚀 Getting Started

### First Time Setup

1. **Visit SmartStudy**

   - Open your web browser
   - Navigate to [SmartStudy URL]
   - You'll see the main dashboard

2. **Upload Your First Document**

   - Click the upload area or drag and drop a file
   - Supported formats: PDF, TXT, DOCX, DOC, PPTX, PPT
   - Wait for text extraction to complete

3. **Generate Your First Quiz**
   - Click "Generate Quiz" after text extraction
   - Customize your quiz settings
   - Wait for AI to create questions
   - Start answering!

## 📚 Core Features

### Document Upload

#### Supported File Types

- **PDF Documents**: Text-based and scanned PDFs
- **Text Files**: .txt, .md, .rtf files
- **Word Documents**: .docx, .doc files
- **PowerPoint**: .pptx, .ppt files
- **Maximum File Size**: 50MB per file

#### Upload Process

1. **Drag & Drop**: Simply drag files onto the upload area
2. **Click to Upload**: Click the upload area to browse files
3. **Multiple Files**: Upload multiple documents at once
4. **Progress Tracking**: See real-time upload progress

#### Text Extraction

- **Automatic Processing**: AI extracts text from your documents
- **OCR Support**: Handles scanned documents and images
- **Format Preservation**: Maintains document structure
- **Error Handling**: Clear feedback if extraction fails

### Quiz Generation

#### Quiz Settings

- **Question Count**: Choose 1-50 questions per quiz
- **Difficulty Level**: Easy, Medium, Hard, or Mixed
- **Question Type**: Multiple Choice, True/False, or Mixed
- **Focus Area**: Specify topics to emphasize (optional)

#### Generation Process

1. **Configure Settings**: Adjust quiz preferences
2. **AI Processing**: SmartStudy analyzes your document
3. **Question Creation**: AI generates relevant questions
4. **Quality Check**: Questions are validated and deduplicated
5. **Ready to Start**: Quiz appears when all questions are ready

#### Question Types

- **Multiple Choice**: Choose from 4 options
- **True/False**: Simple yes/no questions
- **Mixed**: Combination of different types

### Quiz Taking Experience

#### Interface Overview

- **Question Display**: Clear, readable question text
- **Answer Options**: Well-formatted multiple choice options
- **Progress Bar**: Track your quiz progress
- **Navigation**: Previous/Next question buttons
- **Timer**: Optional time tracking (if enabled)

#### Answering Questions

1. **Read Carefully**: Take time to understand the question
2. **Select Answer**: Click on your chosen option
3. **Review**: Double-check your selection
4. **Submit**: Click "Submit Answer" or auto-advance
5. **Feedback**: See immediate feedback and explanation

#### Navigation Controls

- **Previous**: Go back to previous questions
- **Next**: Move to next question
- **Skip**: Skip difficult questions
- **Review**: Review all questions at the end

### Guided Learning

#### What is Guided Learning?

Guided Learning provides step-by-step instruction based on your document content, making complex topics easier to understand.

#### Learning Steps

1. **Introduction**: Overview of the main concepts
2. **Concept Exploration**: Detailed explanations
3. **Practice Questions**: Interactive exercises
4. **Review**: Summary and key takeaways

#### Interactive Features

- **Progress Tracking**: See your learning progress
- **Practice Questions**: Test understanding
- **Explanations**: Detailed concept explanations
- **Navigation**: Move through learning steps

## 🔧 Advanced Features

### Custom API Keys

#### Why Use Custom API Keys?

- **Unlimited Access**: No generation limits
- **Better Performance**: Dedicated API access
- **Cost Control**: Manage your own API usage
- **Privacy**: Your own API key for processing

#### Setting Up Custom API Keys

1. **Get API Key**: Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. **Copy Key**: Copy your API key
3. **Add to Settings**: Paste in SmartStudy settings
4. **Enable**: Toggle custom API key usage
5. **Test**: Generate a quiz to verify

#### Security Notes

- **Local Storage**: Keys stored only in your browser
- **No Server Storage**: Keys never sent to our servers
- **Secure Transmission**: HTTPS encryption for all requests
- **Easy Removal**: Delete keys anytime from settings

### Export Functionality

#### Quiz Export

## 🆘 Troubleshooting

### Common Issues

- **Network Issues**: Check your internet connection

- **No Questions Generated**: Check document content quality

- **Duplicate Questions**: Report to support team

#### Performance Issues

- **Slow Loading**: Check internet connection
- **Interface Lag**: Refresh the page
